# 澄音 CLEAR

双击 **start-player.cmd** 打开，需要 Node.js 22.18 或更新版本。

使用左侧“在线找歌”搜索并下载歌曲和歌词，完成后自动加入曲库。原有本地导入、歌词同步、收藏、队列和三种外观继续可用。

完整说明见 [README.md](README.md)。播放器独立运行，无需 Python 或识别模型。

## Windows 桌面版

双击 `ClearPlayer.exe` 或桌面的“澄音音乐”直接打开独立窗口，无需浏览器和命令窗口。保留与启动入口同级的 `desktop-app` 文件夹。
桌面版曲库与外观保存在 `%APPDATA%\ClearPlayer`；首次打开桌面版时，需要重新导入浏览器版的本地歌曲。

桌面验证：`npm run test:desktop`。打包代码在 `desktop/`，使用说明见 `desktop/README.md`。

## 曲库、播放页与托盘

“我的曲库”显示已导入和已加入曲库的全部歌曲。点击该入口会清空搜索条件。
点击底部歌曲信息或侧栏“正在播放”可打开独立播放页，在右上角选择“黑胶唱片”或“歌词舞台”。两种布局共用播放状态，切换不会打断音乐，选择会记住。
点击关闭按钮会收进系统托盘并继续播放。点击托盘图标恢复；右键图标选择“退出澄音”才能完全退出。
视觉参考：[Folia Major](https://github.com/chthollyphile/folia-major)，实现代码为本项目自行编写。

## 无边界桌面界面与专辑封面

曲库主区域统一滚动，长歌单可以直接滑到最后一首。桌面顶部空白可拖动，右上角保留最小化、最大化/还原、关闭到托盘。
点击黑胶中央可添加或更换本地专辑封面，支持 20 MB 以内的 JPG、PNG、WEBP。内嵌正面封面优先读取；没有封面时显示明确占位，不把默认插画当作真实专辑图。更换封面不会中断播放，重新导入也会保留自选图片。
