# 澄音 CLEAR

Windows 桌面音乐与歌词播放器，采用无边界界面，支持黑胶唱片与歌词舞台、专辑封面、本地曲库，以及雾蓝玻璃、浅色唱片室和极简舞台三种外观。也支持在线找歌、下载音频和 LRC、自动加入曲库。

[更新日志](CHANGELOG.md) · [全部发行版本](https://github.com/LKlingkong/ClearPlayer/releases)

## Windows 桌面版

从 [v1.0.3 Release](https://github.com/LKlingkong/ClearPlayer/releases/tag/v1.0.3) 下载 `ClearPlayer-v1.0.3-win-x64.zip`，完整解压后双击 `ClearPlayer.exe`。请下载 Release 附件中的 Windows 压缩包；GitHub 自动生成的 Source code 是源码包。

已打包版本双击 **ClearPlayer.exe**，或打开 **desktop-app/澄音播放器.exe**。无需安装 Node.js。请保留整个 `desktop-app` 文件夹，并将 `ClearPlayer.exe` 放在其同级目录。

关闭窗口默认收进系统托盘并继续播放；右键托盘图标选择“退出澄音”可完全退出。曲库、设置和下载保存在 `%APPDATA%\ClearPlayer`。

点击黑胶中央可添加或更换专辑封面。播放页可切换黑胶唱片与歌词舞台，切换不会打断播放。视觉设计参考 [Folia Major](https://github.com/chthollyphile/folia-major)，界面代码由本项目自行实现。

唱片以香槟金细环与中心轴点缀；播放背景根据封面缓慢流动，暂停、隐藏窗口或启用系统“减少动态效果”时停止动态。

封面铺满中央金环，长方形图片居中裁切而不拉伸。背景浮尘与光晕根据真实歌曲强弱调整亮度、大小和移动速度，安静时收敛、强段落更明显。音频分析在本机旁路完成，不上传音频，也不改变播放器输出。逐字歌词的 `<1800,-1800>` 等时间标记会自动清理，同时兼容增强 LRC 和毫秒逐字行同步；已有歌词无需重新导入。

封面自动按以下顺序查找：已有/自选封面、音频内嵌图片、同目录同名 JPG/PNG/WEBP、`cover` / `folder` / `front` 图片。浏览器版可将图片与音频一起导入。已导入的歌曲若缺少本地图片，可重新导入原文件读取同目录封面，不会覆盖已有自选封面。

本地仍缺少时，会从 Apple、网易云、QQ 音乐查找封面，保存后离线可用。联网只用歌名、歌手查询，专辑与时长在本机参与比对，不发送音频；可在“播放设置 → 自动联网补全封面”关闭自动查找。多个地区和音源独立回退，支持简繁中文、常见歌手别名与时长辅助比对。明确匹配时自动应用，专辑或版本不确定时保留候选供选择，避免翻唱与现场版本误配。

点击唱片中心或“封面与构图”打开**封面工作室**：可以调整查询信息、选择候选图、导入本地图片，以及调整缩放和位置。带有明显对称纯色留边的图片会在显示时去边，原始图片完整保留；构图可保存，也可关闭自动去边。复杂边框会保守保留，可手动放大。点击曲库中的“补齐封面”可进入工作室，一键为所有缺图歌曲串行限速补齐，查看进度、待确认和未匹配项目，随时停止；已有封面不会被批量覆盖。关闭面板后任务仍会继续，悬浮进度入口可重新打开。

本仓库提供源码，不包含本机歌曲、下载记录、Electron 运行时及打包产物。从源码打包需要 Windows、Node.js 22.18 或更新版本，以及 Electron **42.4.1 Windows x64** 的官方运行时。将运行时压缩包内容解压到 `.verification/electron-runtime/`，确保该目录下包含 `electron.exe`，然后运行：

```sh
npm ci
npm run build
npm run desktop:package
```

打包脚本还需要 Windows 自带的 .NET Framework C# 编译器。完成后生成 `ClearPlayer.exe` 和 `desktop-app/`。详细桌面操作见 [desktop/README.md](desktop/README.md)。

已准备运行时后，可用 `npm run release:package` 生成 Windows x64 便携压缩包和 `SHA256SUMS.txt`；输出位于 `.verification/releases/`，不包含个人曲库、下载目录或本地调试日志。

## 浏览器运行与开发

Windows 双击 **start-player.cmd** 时，会优先打开已打包的桌面版。未打包时需要 **Node.js 22.18 或更新版本**，脚本会安装依赖并在浏览器打开 http://127.0.0.1:5173 。浏览器模式下保留启动窗口，关闭启动窗口即可停止服务。

也可以运行：

```sh
npm install
npm run build
npm start -- --open
```

开发时使用 `npm run dev -- --open`。这两种启动方式都包含下载服务；只用普通静态服务器打开 dist 无法在线找歌。更新源码后重新运行 `npm run build`。无需 Python、识别模型、LenoLang 或 LenoMusic.exe。

## 个人雷达与我的歌单

左侧 **个人雷达** 每天保留一组约 30 首推荐，默认 70% 新发现、30% 曲库重听，可以调整熟悉与探索的比例、换一批、收藏、不感兴趣、保存歌单或整组下载。“我的听感”支持添加偏好标签；文件风格资料、导入歌单标签、收藏、实际收听与跳过记录共同帮助寻找候选。行为与偏好保存在本机；联网查找只传必要的歌曲资料与风格关键词，不上传音频。候选不足显示实际数量；推荐服务故障保留上次结果。

点击 **导入歌单**，粘贴 QQ 音乐或网易云公开歌单分享链接，读取预览后选择“导入并下载”。歌曲顺序会保留，已有同版本音频直接复用，缺失歌曲自动在后台下载。原平台不可用时严格寻找跨音源同版本，不自动替换翻唱、现场版或伴奏；失败条目保留为待补齐。支持暂停、继续、停止与显式重试，软件重开后继续未暂停歌单的任务。相同录音在多个歌单之间共享下载。

歌单支持新建、改名、增删歌曲、上下移动和撤销移除。播放歌单时按该清单前后切歌，缺失音频准备期间可以继续听当前歌曲，后续选择会取消旧的待播放请求。手动“检查更新”可确认补入新增或恢复详情的歌曲，保留自定义名称、顺序及本地收藏；删除歌单不会删除曲库音频。暂不包含平台登录和私密歌单。上游限制或不完整列表会明确提示。

开发验证：`npm run test:discovery` 包含真实浏览器交互和从旧曲库结构升级的数据保留检查。

## 在线找歌与下载

1. 打开左侧 **在线找歌**，选择音源并输入歌曲或歌手。
2. 在结果中点击下载，可同时获取歌词。下载任务支持进度、暂停、继续、取消和重试。
3. 完成后自动加入曲库，不打断正在播放的歌曲；也可以再次加入，或通过保存入口另存音频与歌词。

支持酷我、网易云、酷狗、QQ 和音乐库。部分路径依赖第三方公开接口，可能限流、超时或改变协议，不能保证所有歌曲、付费版本或无损可用。多源搜索保留已成功的结果，音源故障不会影响本地播放。请只下载你有权获取的内容。

浏览器开发模式的文件保存在项目 **downloads/** 目录；桌面版保存在 **%APPDATA%\ClearPlayer\downloads/**。任务历史为对应目录中的 `.history.json`。暂停保留半成品；取消移除半成品，已完成歌曲保留。重启后未完成任务显示为暂停，可继续；服务器不支持可靠续传时会重新下载，避免损坏文件。

移除曲库歌曲不会删除磁盘下载。清理浏览器数据后，磁盘文件仍保留，可以从任务中再次加入。移动或删除磁盘文件后，再次加入/保存可能提示文件缺失。

## 本地音乐与歌词

- 导入或拖入 MP3、FLAC、M4A、OGG、WAV 及 LRC / TXT。具体编码能否播放取决于浏览器。
- 同名歌词自动配对，也可以选中歌曲后单独导入歌词。
- 读取音频标签和封面；LRC 随播放高亮，点击歌词可跳转；TXT 作为纯文本阅读。
- 保留收藏、最近播放、播放队列、顺序/随机/单曲循环、音量、沉浸歌词和三种外观。

歌曲与收藏保存在当前浏览器本地数据库，使用相同地址、端口和浏览器可恢复，刷新不会自动发声。无痕模式、清理站点数据或空间不足可能影响保存。下载成功但浏览器保存失败时，可从任务重新加入。

输入框及按钮之外：空格播放暂停，左右方向键跳转 5 秒，上下方向键调音量，Esc 退出面板。

联网搜索把关键词发送到所选音源；本地音乐不会上传。服务只监听本机地址，默认保留 HTTPS 证书校验。

## 验证

```sh
npm test
npm run build
npm run test:artwork
# 先启动播放器
npm run test:e2e
```

浏览器测试需要 Microsoft Edge。tests/fixtures 是短测试音，不会预填用户曲库。音源测试验证固定响应；下载测试使用本机 HTTP 服务验证文件内容、续传、取消、错误页拒绝、来源限制与历史恢复，不代表第三方接口永远可用。

旧的 Python MP3 歌词识别工程、模型、虚拟环境及专用启动和测试文件已按确认清单移除。目前歌词来自音频标签、本地导入或音源下载。
