澄音 CLEAR · Windows 桌面版

推荐双击项目目录的 ClearPlayer.exe 或桌面上的“澄音音乐”。也可以直接打开本文件夹中的“澄音播放器.exe”。无需安装 Node.js，也无需打开浏览器或命令窗口。

保留整个 desktop-app 文件夹；其中的 DLL、resources 和 locales 是播放器的运行组件，不能只复制一个 EXE。项目目录的 ClearPlayer.exe 是带图标的启动入口，需与 desktop-app 放在一起。

现有的本地导入、歌词同步、三种外观、收藏、队列和在线音乐功能均保留。
点击窗口关闭按钮会收进系统托盘，音乐继续播放。点击托盘图标或再次双击桌面入口即可恢复窗口。
需要完全退出时，右键托盘图标，选择“退出澄音”。真正退出后重新打开会恢复曲库、收藏和外观，不会自动发声。
重复双击会返回已打开的窗口。

曲库、设置和下载保存在 %APPDATA%\ClearPlayer 中，更新播放器文件不会清空这些数据。
桌面版使用独立的数据空间；首次使用请重新导入此前浏览器版本的本地音乐。

原始音乐文件不会因从曲库移除而被删除。

“我的曲库”直接显示全部已加入的歌曲，点击该入口会清除搜索条件。
点击底部歌曲信息或“正在播放”进入播放页，可切换“黑胶唱片”和“歌词舞台”，播放不会中断。
歌词舞台参考 Folia 的大字号与沉浸式排版设计，使用本项目自行实现的界面代码。

界面以“无边界”为主题，窗口顶部空白可拖动，右上角保留最小化、最大化与关闭到托盘。
曲库采用主区域统一滚动，歌曲很多时可直接滚到最后，不会被悬浮播放栏遮住。
黑胶中心显示歌曲内嵌的正面专辑封面；没有封面时显示明确占位。点击唱片中心即可添加或更换 JPG、PNG、WEBP 图片（最大 20 MB）。自选封面会随曲库保存，重新加入下载歌曲时也会保留。
