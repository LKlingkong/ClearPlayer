# 个人雷达与歌单导入验证记录

日期：2026-11-03。实现位于 `codex/radar-playlists`，基于已发布的 v1.0.0；本次不改变既有 GitHub Release。

## 已完成

- 每日约 30 首、默认新旧 70/30、探索比例调节、换一批、推荐理由、收藏、负反馈、手动偏好标签、结果持久保存及离线保留。
- QQ / 网易云公开歌单分享文字与链接解析、白名单短链跳转、完整性提示、预览确认、后台自动补齐、严格同版本跨源回退。
- 歌单新建、改名、增删、排序、撤销移除、手动更新差异；共享下载与显式恢复；停止/暂停/继续/重试和重开恢复。
- 独立歌曲上下文队列；等待新歌期间继续播放；后续用户选择使旧请求过期；所选歌曲优先准备。
- 三套主题、可达列表末尾、导航滚动保留、原生焦点对话框、过期响应保护、减少动态效果设置。
- 桌面同源图片代理复用原有封面服务的官方 CDN 白名单、图片格式校验、并发与内存限制，没有放宽 Electron CSP。
