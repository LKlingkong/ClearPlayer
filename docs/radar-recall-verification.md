# 本地曲库雷达新歌召回修复

2026-11-04，基于 v1.0.1，分支 `codex/fix-radar-recall`。本次交付为本地桌面更新。

## 修复内容

- 本地 MP3 没有平台编号时，通过歌曲及歌手资料寻找推荐参考。支持明确歌手别名和合唱顺序，音频下载仍使用严格的录音版本匹配。
- 最多六首参考歌曲均参与，尽量分散歌手。相似歌曲、共同收录的歌单、已核实风格及 QQ 相关作品共同提供候选，排序兼顾不同歌手。
- 歌手搜索返回的歌单必须实际包含相关歌手，才能作为风格依据；歌单标题的营销文字不足以证明关联。风格查询返回不符合请求标签的热门列表时不采用。
- 同一张歌单可先用于风格上下文，再提供风格候选，复用详情请求而不误跳过有效歌曲。
- 参考歌曲查询有独立预算，QQ 后备提前并行，避免一个慢来源耗尽全部时间。
- 正常空结果不缓存；接口业务错误有明确状态；手动刷新重新查询并推进候选页。保留旧结果时也推进页码。
- 同平台同歌曲编号（包括 QQ 音质后缀差异）不因标题修订而被算作新歌。曲库、历史和负反馈继续过滤。
- 旧版只有曲库重听的快照进入雷达后自动尝试恢复一次。仍无新歌时显示“重新寻找新歌”，不把旧歌重排当作完成。
