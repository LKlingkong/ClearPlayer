# 澄音 CLEAR v1.0.0

澄音是一款以本地聆听为主的 Windows 桌面音乐播放器，采用无边界界面、黑胶唱片与沉浸歌词布局。

## Windows 下载与启动

下载附件 **ClearPlayer-v1.0.0-win-x64.zip**，完整解压后双击 **ClearPlayer.exe**。无需安装 Node.js，保留同目录的 `desktop-app` 文件夹。`SHA256SUMS.txt` 提供压缩包校验值。

## 本次功能

- 本地导入 MP3、FLAC、M4A、OGG、WAV 和 LRC / TXT；保留收藏、最近播放、队列、顺序/随机/单曲循环、音量和歌词定位。
- 无边界桌面窗口、雾蓝玻璃 / 浅色唱片室 / 极简舞台三种外观，黑胶唱片与歌词舞台随时切换。
- 金色唱片、专辑封面、多层流色光带和随真实音乐强弱变化的粒子效果；暂停、隐藏或系统减少动态时停止动画。
- 自动读取内嵌与同目录图片，通过 Apple、网易云、QQ 音乐补充封面；明确匹配自动采用，不确定时提供候选图。
- 封面工作室支持整库补图、进度与停止、候选选择、去除明显纯色留边，以及保存缩放和位置，原图完整保留。
- 兼容增强 LRC 与毫秒逐字歌词，清理 `<1800,-1800>` 等时间标记；修复长曲库滚动到底的问题。
- 在线搜索、下载任务暂停/继续/重试、音频与歌词保存、完成后加入曲库。
- 关闭窗口收进托盘继续播放，重复打开恢复已有窗口。

## 更新与数据

更新前从托盘选择 **退出澄音**，再解压到新目录运行。曲库、设置和桌面下载保存在 `%APPDATA%\ClearPlayer`，更新程序文件不会清空这些数据；移除曲库歌曲不会删除原始音乐文件。

联网补图仅查询歌曲信息，不上传音频，可在播放设置中关闭自动补全。音源和封面服务的可用性取决于上游；未准确匹配的封面仍可手动选择。第三方许可和说明随压缩包附带。
