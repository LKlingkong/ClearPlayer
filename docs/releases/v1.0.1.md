# 澄音 CLEAR v1.0.1

这次更新加入个人雷达和 QQ／网易云公开歌单导入，并改善后台下载与播放切换的连贯性。

## 下载与使用

下载 **ClearPlayer-v1.0.1-win-x64.zip**，完整解压后双击 **ClearPlayer.exe**。保留同目录的 `desktop-app` 文件夹，无需安装 Node.js。附件 `SHA256SUMS.txt` 提供压缩包校验值。

从 v1.0.0 更新时，先通过托盘菜单退出旧播放器，再在新解压目录启动。原有曲库、收藏、歌词、封面与构图设置会保留，资料仍在 `%APPDATA%\ClearPlayer`。请勿删除该资料目录。

## 个人雷达

- 每天保留一组约 30 首，默认 70% 新发现、30% 曲库重听；探索比例可调，支持换一批。
- 结合收藏、实际收听、跳过和偏好标签寻找候选，展示推荐理由。
- 支持收藏、不感兴趣、加入歌单、保存当日歌单和整组下载。
- 偏好保存在本机，不上传音频；候选不足时显示实际数量，推荐服务故障时保留上次结果。

## 歌单导入与管理

- 支持粘贴 QQ 音乐、网易云公开歌单分享链接或分享文字，预览后导入。
- 保留歌曲顺序，优先匹配本地同版本音频，自动下载全部缺失歌曲。
- 原音源不可用时严格寻找其他音源的同一版本，不自动替换翻唱、现场版或伴奏。
- 后台下载支持暂停、继续、停止和重试；未暂停歌单在软件重开后继续准备。
- 歌单支持新建、改名、添加、移除、排序、撤销移除及手动检查源更新；删除清单不会删除曲库音频。

## 更顺畅的交互

- 切换雷达、歌单和播放页时保留当前播放与滚动位置。
- 选中的未下载歌曲优先准备；等待期间仍可听当前歌曲，后续选择不会被旧请求抢走。
- 多张歌单共享同一录音的下载，暂停或删除其中一张不会误停另一张。
- 修复显式补回已移除音频、暂缺歌曲详情恢复、存储失败反复入库和过期弹窗覆盖等边界问题。
- 新页面跟随三套主题，支持键盘对话框与减少动态效果；歌单封面适配桌面安全加载。

## 验证与适用范围

116 项自动测试通过，并验证了真实浏览器交互、旧曲库升级及 Windows 桌面窗口。公开样本验证：网易云歌单 200/200 首、QQ 歌单 17/17 首元数据完整，真实封面可读取。

当前支持公开歌单，暂不包含平台登录或私密歌单。上游接口、歌曲权限与地区限制可能影响完整读取或音频获取；无法获取的内容会显示状态并保留重试入口。
