# 澄音 CLEAR v1.0.3

修复个人雷达只有 9 首曲库歌曲、没有新歌的问题，并扩展曲风相关的跨歌手推荐。

## 下载与更新

下载 **ClearPlayer-v1.0.3-win-x64.zip**，完整解压后双击 **ClearPlayer.exe**。保留同目录 `desktop-app` 文件夹，无需安装 Node.js。校验文件为 **SHA256SUMS.txt**，压缩包内附 **CHANGELOG.md**。

更新前通过托盘菜单选择“退出澄音”，再在新解压目录启动。曲库、收藏、歌词、封面构图、偏好与资料继续保存在 `%APPDATA%\ClearPlayer`，无需清空或重新导入。

## 雷达修复与改进

- 补齐本地歌曲没有平台编号时的推荐路径，识别明确歌手别名和合唱信息。
- 相似歌曲、共同歌单、已核实风格与 QQ 相关作品共同提供候选，扩展到曲风相近的不同歌手，并标明推荐理由。
- 使用最多六首参考歌曲，兼顾歌手多样性；音频下载仍严格匹配录音版本。
- 空结果不长缓存，“换一批”真正重新查询并推进候选页。
- 慢来源不再耗尽其他来源的全部等待时间；同一歌单复用时不遗漏有效新歌。
- 根据平台编号排除已有歌曲，避免标题修订造成重复推荐。
- 旧的“仅9首旧歌”记录进入雷达后自动尝试恢复；来源故障时保留已有结果，并提供重新寻找入口。
