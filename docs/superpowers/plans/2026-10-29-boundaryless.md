# 无边界界面与曲库滚动修复

用户明确要求：修复歌单滚动不到最后一首；以无边界作为整体主题，继续学习 Folia 的沉浸设计；唱片中心使用专辑封面。

- [x] 用长曲库和小窗口复现底部歌曲被播放栏遮挡的问题；改为曲库主区域单层滚动，取消列表内部的固定高度与滚动截断。
- [x] 统一为连续画布、开放导航、轻量当前歌曲条和悬浮播放控制；保留三种色彩预设、黑胶与歌词舞台以及可见键盘焦点。
- [x] 桌面窗口使用融合式窗口控件和可拖动区域，保留最小化、最大化、关闭到托盘及明确退出。
- [x] 唱片中心优先显示内嵌正面专辑封面；没有封面时明确显示占位，并可本地添加或更换封面；持久化且不打断播放。
- [x] 真实 EXE 验证长列表末行可见/可点击、不同窗口大小、封面解析与更换、托盘和重新打开。构建、回归后更新桌面版，不删除用户数据。


## 验证与交付

- 旧版失败已复现：1440x1000 下，最后一首底部为 992.5px，播放栏顶部 893px，导致末行被遮挡。
- 改为 page-content 单层滚动后，60 首曲库在 1440x1000、1100x700、800x600 下均可滚到底、看全最后一首并点击播放；播放队列末行同样可见。
- 窗口改为 frame:false，通过隔离 preload 仅暴露三个窗口操作。主进程验证消息来自本窗口；原有 sandbox、contextIsolation 与关闭到托盘保持。
- 黑胶中心优先使用正面内嵌专辑封面；明确缺图占位，支持本地更换并持久化。真实 MP3 的封面与独立 FFmpeg 提取内容哈希一致，手动更换不打断播放。
- 独立复核发现重新加入带内嵌封面的音频会覆盖手选图；新增用例先复现 256px 替换了 128px 自选图，再修复优先保留现有封面，刷新和重新加入回归通过。
- npm test 53/53；既有四组界面端到端用例通过；封面重新导入回归通过；生产构建与桌面打包完成。桌面测试包含托盘播放、布局与主题、暂停歌词定位及持久化。
- 所有长曲库、音频与图片验证使用独立测试数据目录，未修改用户原有曲库。
