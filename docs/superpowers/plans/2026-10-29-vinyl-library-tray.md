# 黑胶播放页、完整曲库与托盘

用户要求完整曲库、关闭时自动最小化，并提供 QQ 音乐截图作为播放页参考。沿用现有三种外观和全部播放器功能。

- [x] 曲库使用主要空间显示歌曲列表，当前歌曲缩成紧凑播放条；点击“我的曲库”清空搜索，显示全部歌曲。
- [x] 独立播放页：左侧歌名与同步歌词、右侧超大唱片；播放旋转、暂停保留角度，保留换肤与减少动态效果。
- [x] 关闭收进系统托盘且继续播放；托盘恢复、播放控制和退出；重复双击恢复已有窗口。
- [x] EXE 验证完整列表、搜索复原、唱片、歌词、隐藏播放及恢复、真正退出与持久化。
- [x] 重新打包、检查桌面截图与原有测试，保留用户数据并打开更新版。

## 追加参考与实现

用户指定参考 https://github.com/chthollyphile/folia-major ，并强调其沉浸 UI 的设计感。已查看官方 README 与 Lumi/Fume 预览，采用大字歌词、前后句淡出、安静背景和浮动控制栏的设计方向。保留 QQ 风格的唱片页，并新增可记忆的“歌词舞台”布局。参考项目代码和图片没有并入本项目。

桌面实测已通过：曲库直接可见、搜索后回到全部歌曲、唱片转动与暂停、布局与主题切换不断音、隐藏到托盘后时间继续前进、重复启动恢复、退出重开恢复曲库和收藏。独立复核发现暂停时打开隐藏歌词页不重定位，已先复现失败，再通过 visible 属性使显示时重新定位；回归通过。
