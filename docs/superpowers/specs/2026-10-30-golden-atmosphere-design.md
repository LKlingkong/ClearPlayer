# 金色唱片、自动封面与流动背景

用户授权自行调整样式并直接实现。保留现有无边界布局、歌词舞台、三种外观和播放行为。

## 视觉
唱片作为唯一视觉焦点：石墨黑 #172126、香槟金 #d8ba78、深金 #877040、象牙白 #f2ebda。沿用现有宋体标题与系统无衬线正文，时间使用等宽数字。两道细金环、金色中心轴和柔和反光强调唱片质感，不改变专辑封面大小。背景使用放大的模糊封面与低速流动的光晕，换封面时交叉淡入。无封面时使用主题配色。暂停、窗口隐藏和系统减少动态效果时暂停动画；歌词始终具有对比度。

## 封面
优先级：已有/手动封面 > 音频内嵌封面 > 本地同目录同名图片 > cover/folder/front 图片 > 联网严格匹配。桌面通过只接受真实 File 的受限桥接查找同目录 JPG/PNG/WEBP，不提供任意路径读取。浏览器可将同名图片与歌曲一起导入。

联网使用 Apple iTunes Search 的歌曲元数据与官方 CDN 图片，不需要用户 API key，仅发送歌名、歌手和专辑。只有歌名与歌手精确规范化匹配、且已有专辑时专辑也匹配，才使用候选封面；拒绝翻唱和现场版本的模糊匹配。限制请求时间、大小、图片格式和 CDN 域名。保存 Blob 到已有曲库，不改变音频资源。播放设置提供自动联网开关，默认开启；没有匹配时保留占位并可重试或手动选图。只为当前歌曲补全，避免一次请求全部曲库。请求完成时检查最新歌曲仍存在且仍无封面，绝不覆盖手动选择。

实际联网发现中国区缺少部分中文歌曲、香港区使用繁体标签，因此使用中国区查询后回退香港区，并新增 opencc-js 1.4.0 做简繁转换；转换后依旧严格匹配歌名、歌手及专辑。背景状态同时监听原生 show/hide/minimize/restore，避免托盘持续播放配置导致 document.hidden 不可靠。

## 验证
测试本地匹配优先级、路径/大小限制、联网精确匹配与拒绝错误内容；界面测试自动补全、持久化、手动封面竞态、播放不中断、动态效果与减少动态偏好。重新构建并更新桌面包，保留真实用户数据。本次无需推送或发布。
