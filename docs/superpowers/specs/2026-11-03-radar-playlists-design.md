# 个人雷达与公开歌单导入

用户已于 2026-11-03 确认以下设计并要求交互更丝滑，授权完成设计、实现、验证。

## 使用体验

个人雷达每天固定约 30 首，默认 70% 新歌 / 30% 曲库歌曲，探索比例可调。新歌指本机曲库没有且本机历史未听过的歌曲。支持换一批、播放、收藏、不感兴趣、加入歌单、整组下载。候选不足时明确显示实际数量，不能假装达到比例。联网失败保留上次结果，并提供离线重听。

推荐使用本地偏好排序：文件 genre、导入歌单标签、常听歌手、收藏、完整收听、累计收听、重复播放、跳过、不喜欢。标签需要记录来源；歌单标签只是弱关联，不伪装成歌曲的确定标签。用户可修正偏好。不需要 AI 账户。候选来自公开相似歌曲和风格歌单，不是以排行榜冒充个人推荐。

QQ 音乐、网易云公开分享链接导入：解析预览 → 确认导入 → 立即显示歌单 → 后台自动补齐所有缺失歌曲。顺序及不可用条目保留，优先严格匹配本地同歌手、同版本歌曲；跨源只能选同版本。失败单曲标记待补齐，支持重试。后台工作有限并发，暂停/恢复/取消能持久保存；重开软件后不丢歌单或任务。

我的歌单支持新建、改名、添加、移除、调整顺序、删除及播放。删除清单不删除曲库音频。手动检查源歌单更新，用户确认新增项才补入，保留本地修改与被远端移除的歌曲。同源重复导入进入原歌单，不创建副本、不重复下载。

## 视觉与交互

延续无边界、雾蓝与香槟金的音乐空间，跟随三套主题。雷达的标志元素是一张由封面组成的轨道，光晕有节制地呼吸；其余内容安静、清晰。色彩沿用 --bg #101922、--text #e8eff3、--secondary #a1b1bd、--accent #a4dfd5，加香槟 #d9bf87。标题 Segoe UI/Microsoft YaHei UI，正文同族，时间与数量使用等宽数字。

左侧固定雷达入口与可滚动歌单分组。页面保持挂载、各自保存滚动位置；当前音频资源不随页面/收藏/主题变化。播放某歌单后上一首/下一首按该清单走，未下载曲目按需准备且显示状态。导入对话框有焦点管理、Esc、可关闭的解析过程和过期响应保护。按钮有即时忙碌/完成反馈；动作不会重复提交；无阻塞浏览器 alert/confirm/prompt。列表末尾可到达，支持小屏、键盘、reduced-motion。

## 实现边界

IndexedDB 升级，保留 tracks/downloadImports；新增 discovery 文档存储，保存歌单、雷达快照与偏好。歌曲引用独立于音频 Track，保存平台 source/id 和版本信息，避免下载任务 ID 造成同歌重复。队列独立于完整曲库。听歌计量基于实际音频播放时间增量，seek/暂停不计为听完。

只解析 QQ/网易白名单链接与短链，禁止任意地址请求。分页核对条目数量，不完整时显示实际与总数并允许重试。公开列表读取与音频获取分开处理；读取成功不代表每首音频一定可用。

已实测网易公开榜单 200/200、QQ 公开歌单 17/17，网易相似歌曲返回 5 首；其他大歌单及链接变体继续验证。

## 验证

单元测试覆盖分享链接/短链边界、版本匹配、去重、混排比例、反馈、历史计量。服务测试替代远端边界，验证分页/失败、歌曲注册、跨源严格回退。浏览器测试使用真实音频/IndexedDB，验证预览导入自动下载、重开恢复、控制任务、编辑、更新差异、雷达操作、队列、滚动以及音频不中断。最后运行原有测试、构建、桌面回归，更新本地桌面构建并启动。
